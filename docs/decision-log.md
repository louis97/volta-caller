# Volta decision log

This log records the product choices that shape Volta's first commercial
workflow.

| Decision                    | Alternatives considered                                                                         | Chosen approach and rationale                                                                                                                                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Carrier selection authority | Let Volta automatically choose the lowest compliant quote; ask a coordinator to choose by phone | The dashboard customer selects a reviewed quote. Commercial preference can include price, trust, capacity, and service quality—context an agent should not infer.                                             |
| Booking authority           | Book during the initial carrier negotiation; require a second customer action before every step | Volta only confirms after an explicit dashboard selection. This keeps discovery fast while making commitment authorization unambiguous.                                                                       |
| Mandate enforcement         | Prompt-only rules; allow agents to make verbal exceptions                                       | The backend validates price, timing, cargo, state, and selected terms. Prompts guide conversation; software enforces authority.                                                                               |
| Carrier outreach            | Sequential coordinator calls; fully autonomous lowest-price auction                             | Volta collects and structures carrier offers, while the customer retains final choice. The product improves speed without sacrificing governance.                                                             |
| Changed confirmation terms  | Renegotiate automatically; silently choose another offer                                        | Fail the confirmation and escalate. A changed offer requires a fresh commercial decision and must not become an accidental booking.                                                                           |
| Quote data from calls       | Manual coordinator transcription; store raw transcripts only                                    | Persist structured quote records and extract final price, currency, agreement time, and summary from completed-call transcripts. This improves dashboard visibility while retaining the transcript for audit. |
| Exception response          | Leave incidents in chat/phone notes; automate replacement carriers                              | Capture verified facts, assess delivery feasibility against the mandate, notify the dashboard when risk exceeds the deadline, and escalate to a human. Replacement sourcing remains out of scope.             |
| Notification delivery       | Ephemeral toasts only; email/SMS as the first channel                                           | Persist shipment events first, then refresh the dashboard in real time. Events survive reloads and create an auditable record.                                                                                |
| Inbound operations channel  | Build inbound phone handling now; require a separate portal                                     | Keep the outbound carrier workflow focused. WhatsApp is the planned inbound channel for mandate intake and incidents, using the same backend records and notifications.                                       |
| Integration strategy        | Full TMS/ERP integration before validation; no integration model                                | Start with mocked integrations and a pilot lane. Prove operational value, then connect the buyer's TMS/ERP through defined backend interfaces.                                                                |
